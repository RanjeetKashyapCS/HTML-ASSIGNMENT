# Assignment 4: Git Repository with Three Meaningful Commits

**Original task:** Create a Git repository and make at least three meaningful commits.

**Beginner solution note:** Run these commands in your own project. Do not make empty or misleading commits.

## How to run
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**, or open the file in your browser.
4. Replace sample details such as `Your Name`, college name, and email with your own details.

## Files
- `index.html` — HTML structure.
- `style.css` — CSS styling.
