Git: Three Meaningful Commits

Open a terminal inside your project folder and run:

git init
git add .
git commit -m "Add first HTML page"

Then make a real change and commit it:

git add .
git commit -m "Add page content"

Make another change and commit it:

git add .
git commit -m "Add basic CSS styling"

Configure your Git name and email first if Git asks you to. Each commit should match a real change.
