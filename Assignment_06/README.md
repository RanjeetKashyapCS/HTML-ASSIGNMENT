# Assignment 6: Basic HTML Page with Title and Headings

**Original task:** Build a basic HTML page with a title and a few headings.

**Beginner solution note:** A basic page with a title and headings.

## How to run
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**, or open the file in your browser.
4. Replace sample details such as `Your Name`, college name, and email with your own details.

## Files
- `index.html` — HTML structure.
- `style.css` — CSS styling.
