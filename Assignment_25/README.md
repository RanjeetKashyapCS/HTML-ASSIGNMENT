# Assignment 25: Styled Multi-page Project and Design Note

**Original task:** Style the multi-page project and document design choices.

**Beginner solution note:** The design note is included on the page; apply the same stylesheet to all four pages.

## How to run
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**, or open the file in your browser.
4. Replace sample details such as `Your Name`, college name, and email with your own details.

- `index.html` — HTML structure.
- `style.css` — CSS styling.
